# Power BI - HR Attrition Dashboard

## 📊 Project Overview
Capstone Project analyzing Employee Attrition using Power BI. Analyzed 1470 employees data to identify key attrition factors.

**Key Finding:** 237 employees left (16.1% attrition rate)

## 🎯 Objectives
- Identify attrition patterns
- Analyze impact of Department, Age, Income, Overtime
- Provide actionable HR recommendations

## 🔑 Key Insights
- Sales dept has highest attrition
- Age 26-35 most attrited group
- Overtime = Major attrition factor (53% of leavers did OT)
- Single employees attrite more
- Low Work-Life Balance drives attrition
